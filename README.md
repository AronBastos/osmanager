# 🚀 OSManager - Sistema de Gestão de Ordens de Serviço

Sistema completo para gestão de oficinas mecânicas desenvolvido em **Java 17** com **JSF/PrimeFaces**, **Hibernate** e **MySQL**.

## 🛠️ Tecnologias

- **Java 17** | **Maven 3.8.1+** | **MySQL 8.0** | **Git**
- **JSF/PrimeFaces 12.0.0** (interface web)
- **Hibernate 5.6.15** (ORM) | **JUnit 5 + Mockito** (testes)
- **Log4j 2.23.1** (logging)

---

## ⚡ Quick Start (5 minutos)

```bash
# 1. Compilar
mvn clean install

# 2. Executar testes
mvn test

# 3. Gerar WAR
mvn package

# 4. Ler documentação
# Abra: docs/README.md
```
